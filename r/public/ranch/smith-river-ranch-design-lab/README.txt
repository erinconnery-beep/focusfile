SMITH RIVER RANCH — FULL-SITE DESIGN LAB FOR v0

What this package contains
- index.html: the complete existing site and immutable source of truth
- assets/: every original image, map, icon, monogram, and bundled font from the supplied ZIP
- v0-prompt.txt: the controlled three-treatment build brief
- SOURCE-CHECKSUMS.txt: checksums for verifying that source files did not drift

How to use it
1. Drag smith-river-ranch-v0-design-lab.zip into a new v0 chat.
2. Paste the contents of v0-prompt.txt as the first message. If v0 exposes the text file directly, you may simply tell it to follow that prompt exactly.
3. Ask v0 to finish all three routes before critiquing them. Compare the same moments in A, B, and C rather than accepting changes to content or imagery.

Important
The original site is deliberately intact. The brief permits composition and presentation changes only. It forbids generated or replacement imagery, new copy, new facts, omitted sections, and invented ranch-facing features.
